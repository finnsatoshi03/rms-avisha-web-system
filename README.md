# RMS Avisha Web System

A comprehensive Job Order and Rental Management System for service-based businesses, built with modern web technologies.

## Overview

RMS Avisha Web System is designed to streamline service operations, manage job orders, track technicians, handle client information, and provide comprehensive business analytics. The system offers both job order tracking and rental management with a focus on operational efficiency and data-driven decision making.

## Features

- **Dashboard Analytics:** Visualize key business metrics, financial performance, and technician productivity
- **Job Order Management:** Create, track, and manage service job orders from request to completion
- **Technician Management:** Track technician performance, assignments, and work history
- **Client Management:** Maintain a database of clients with their service history
- **Materials Inventory:** Track materials used for services
- **Expense Tracking:** Record and categorize business expenses
- **Multi-branch Support:** Separate data views for different business locations (Taytay, Pasig)
- **Role-based Access Control:** Different permissions for managers and regular users
- **Financial Reporting:** Generate and export financial reports
- **Interactive Charts:** Visualize business data through various chart types
- **Responsive Design:** Works across desktop and mobile devices

## Technology Stack

- **Frontend Framework:** React with TypeScript
- **Build Tool:** Vite
- **Routing:** React Router DOM
- **UI Components:** Radix UI, Shadcn components
- **Styling:** TailwindCSS
- **State Management:** React Query
- **Backend Integration:** Supabase
- **Charts and Visualizations:** Recharts
- **Form Handling:** React Hook Form with Zod validation
- **Notifications:** React Hot Toast
- **PDF Generation:** React PDF Renderer
- **Date Handling:** date-fns

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/rms-avisha-web-system.git
cd rms-avisha-web-system
```

2. Install dependencies

```bash
npm install
# or
yarn install
```

3. Start the development server

```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Build for Production

```bash
npm run build
# or
yarn build
```
